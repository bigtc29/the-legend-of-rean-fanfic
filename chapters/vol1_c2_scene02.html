คลื่นเสียงจ้อกแจ้กจอแจของนักเรียนใหม่สองเผ่าพันธุ์ ทั้ง มนุษย์ (Humans) และ โนพอน (Nopon) นับร้อยชีวิต กำลังส่งเสียงพูดคุย แลกเปลี่ยนข้อมูล และจับกลุ่มแสดงอำนาจกันอย่างคึกคัก

ทว่าโครงสร้างทางสังคมอันเข้มงวดของจักรวรรดิเอเรโบเนีย ได้ถูกขีดเส้นแบ่งแยกไว้อย่างชัดเจนจนแทบมองเห็นได้ด้วยตาเปล่า:

  • ปีกฝั่งซ้ายของหอประชุม: คืออาณาเขตของ Class I และ Class II (นักเรียนขุนนาง) ผู้แต่งกายด้วยชุดเสื้อสูทเครื่องแบบสีขาวบริสุทธิ์ขลิบแถบสีเทาเงิน แต่ละคนนั่งหลังตรง เชิดคางสูง ถือพัดขนนกและไม้เท้าหัวอัญมณี พูดคุยด้วยสำเนียงชนชั้นสูงอันเย่อหยิ่ง
  • ปีกฝั่งขวาของหอประชุม: คืออาณาเขตของ Class III, Class IV และ Class V (นักเรียนสามัญชน) ในชุดเสื้อสูทสีเขียวมรกตสดใส แต่ละคนนั่งบนม้านั่งไม้แถวยาว บรรยากาศเต็มไปด้วยความกระตือรือร้น ปะปนไปกับกลุ่มประชากรโนพอนร่างกลมปุ๊กลุกขนปุยหลากสีสันที่กำลังนั่งกระดิกหู แย่งกันกินขนมปังอบออร์บัลอย่างเอร็ดอร่อย

และท่ามกลางเส้นแบ่งขั้วอำนาจอันตึงเครียดระหว่างขุนนางเสื้อขาวและสามัญชนเสื้อเขียวนั้นเอง...

ร่างสูงโปร่งหนึ่งร้อยเจ็ดสิบแปดเซนติเมตรของชายหนุ่มคนหนึ่ง ก็ก้าวเดินผ่ากลางทางเดินพรมแดงเข้ามาอย่างสง่าผ่าเผย

ชายหนุ่มคนนั้นคือ รีน ชวาเซอร์ (Rean Schwarzer) ทายาทอันดับหนึ่งแห่งตระกูลชีคชวาเซอร์มหาเศรษฐีแปดแสนล้านล้านแห่งยูมีร์ดูไบ!

ผู้เพิ่งผ่านการชำระล้างคราบเขม่าดำ 2T และผ่านมหาศึกถล่มเตียง 45 นาทีสามยกเต็มสูบจากโรงแรมม่านรูดทริสต้ามาหมาดๆ ผิวพรรณของเขาในยามนี้ขาวเนียนผุดผ่อง เปล่งปลั่งด้วยออร่ามานาแห่งกามารมณ์ที่ได้รับการเติมเต็มจนแตะ 100.0% เส้นผมสีดำขลับตัดแต่งทรงทันสมัยรับกับใบหน้าคมคาย แว่นตาดำชวาเซอร์โพลาไรซ์เหน็บไว้ที่กระเป๋าเสื้อสูทด้านนอกอย่างมีระดับ

และที่สำคัญที่สุด... เขาไม่ได้สวมเครื่องแบบสีขาวของขุนนาง และไม่ได้สวมเครื่องแบบสีเขียวของสามัญชน... แต่เขาสวม "เสื้อสูทเบลเซอร์สีแดงชาด (Crimson Blazer)" ตัดเย็บด้วยผ้าทอเนื้อดีที่สุด ดิ้นทองคำแท้ปักตราสัญลักษณ์สถาบันทอร์สที่อกซ้าย กางเกงสแล็คสีดำขลิบทอง และเนกไทสีเขียวเข้มรีดกลีบคมกริบระดับมิลลิเมตร!

สายตานับร้อยคู่ทั้งจากฝั่งเสื้อขาวและเสื้อเขียว ต่างหันขวับมาจับจ้องที่ร่างของชีคหนุ่มสูทแดงเป็นตาเดียว!
