🏍️ ช่วงที่ 1: บิดหมดปลอกออกจากยูมีร์, ด่านศุลกากรมด-โนพอน และสะพานลอยฟ้าข้ามไททัน

แสงเงินแสงทองแห่งรุ่งอรุณวันใหม่ของวันที่สามสิบเอ็ดมีนาคม ศักราชเซมูเรียหนึ่งพันสองร้อยสี่ สาดส่องผ่านม่านหมอกสีทองคำเหนือยอดเขาหิมะแห่งมหานครยูมีร์ดูไบ ลมภูเขาอันเย็นยะเยือกพัดกรรโชกผ่านแนวสนโบราณ ทว่าเบื้องล่างบริเวณประตูด่านตรวจใหญ่ทิศใต้ "Ymir Sovereign Gate" บรรยากาศกลับร้อนระอุและคละคลุ้งไปด้วยควันขาวฟุ้งกระจายที่มีกลิ่นหอมหวานสังเคราะห์ชวนเวียนหัวของน้ำมันเครื่องสองจังหวะกลิ่นสตรอว์เบอร์รีเข้มข้น!

บรึ้มมมม— แป๊ดดดด! แป๊ด! แป๊ด! แป๊ดดดดดดดดดด!

เสียงเครื่องยนต์สูบเดี่ยวขนาดหนึ่งร้อยห้าสิบซีซีระบายความร้อนด้วยน้ำของ Kawasaki Serpico SS 150cc 2T คันงามสีเขียวมุกตัดดำขลิบทอง แผดเสียงคำรามลั่นสะเทือนไปทั่วหุบเขา ท่อสูตรคอเลื้อยสแตนเลสเชื่อมมือปลายกระบอกสีแดงสดอันเลื่องชื่อจากสำนักแต่งในตำนาน "ท่อแดง บางทราย" พ่นลูกไฟเล็กๆ และละอองไอควันขาวพวยพุ่งออกมาเป็นสายยาวตามจังหวะการบิดคันเร่งเบิ้ลเครื่องวอร์มเครื่องยนต์ของชีคหนุ่ม

บนอานเบาะปาดเรียบสีดำปักดิ้นทองคำ รีน ชวาเซอร์ (Rean Schwarzer) ทายาทมหาเศรษฐีแห่งยูมีร์ดูไบในวัยยี่สิบปีบริบูรณ์ นั่งคร่อมตัวรถอย่างสง่างาม ร่างกายกำยำท่อนบนสวมทับด้วยชุดคลุมบิชต์ (Bisht) ไหมทองคำแท้ยี่สิบสี่กะรัตที่ชายผ้าพลิ้วไสวสะบัดลู่ไปตามกระแสลม ใบหน้าคมเข้มสวม "แว่นตาดำชวาเซอร์โพลาไรซ์เกรดกันสะเก็ดระเบิด" ดำมืดสนิทสะท้อนแสงแดดยามเช้าอย่างเยือกเย็น ที่เอวซ้ายเหน็บปลอกหนังบรรจุมีดแมเชตเต้คู่ขนาดสิบแปดนิ้วเหล็กกล้าไฮคาร์บอนขัดเงาแวววาว และที่กระเป๋าเสื้อด้านในบรรจุเช็คเงินสดส่วนตัวมูลค่าห้าพันล้านมิราที่ชีคเตโอเพิ่งเซ็นมอบให้เมื่อวานซืน

บริเวณท้ายเบาะหลัง กล่องสัมภาระเดินทางเคลือบทองคำแท้และกระป๋องน้ำมันเครื่อง คาสตรอล ทูที กลิ่นสตรอว์เบอร์รีจำนวนหนึ่งโหล ถูกมัดตรึงแน่นหนาด้วยตาข่ายเชือกถักควอนตัมสีเขียวสะท้อนแสง

"ตรวจเอกสารการผ่านด่านและใบรับรองมาตรฐานมลพิษออร์บัลขอรับ!"

นายทหารกองรักษาการณ์จักรวรรดิร่างสูงใหญ่ในชุดเกราะเหล็กเต็มยศยืนตรงทำความเคารพอย่างขึงขัง เคียงข้างกับ "เจ้าหน้าที่ศุลกากรโนพอน" ร่างกลมปุ๊กลุกขนปุยสีฟ้าสดใส สวมหมวกกะลาสีสีขาวและแว่นขยายข้างเดียว โนพอนตัวน้อยยืนเขย่งปลายเท้าอยู่บนแท่นหินอ่อน มือสองข้างถือกระดานชนวนหินชนวนศักดิ์สิทธิ์กำลังใช้แท่งถ่านเขียนโค้ดภาษาทางการ AOS-CX CLI ด้วยความรวดเร็วดั่งพายุหมุน

Ymir-Gate-SW01(config)# interface vlan 100 name BIKER_DEPARTURE
Ymir-Gate-SW01(config-if)# ip address 10.1204.1.1/24
Ymir-Gate-SW01(config-if)# permit host rean-serpico-2t out-interface trans-highway
Ymir-Gate-SW01(config-if)# exit && write memory

แชะ! เจ้าหน้าที่โนพอนตบกระดานชนวนเสียงดังฟังชัด ก่อนจะหันมาพยักหน้าหงึกๆ หูยาวสองข้างสะบัดไปมาด้วยความตื่นเต้น

"ระบบอนุมัติเส้นทางเรียบร้อยแล้วโมะ! ควันขาวกลิ่นสตรอว์เบอร์รีของท่านชีครีนผ่านเกณฑ์มาตรฐานมลพิษระดับอนุรักษ์ธรรมชาติพิเศษของมหาเอมิเรตส์ยูมีร์ร้อยเปอร์เซ็นต์โมะ! ขอให้ท่านชีคบิดคันเร่งข้ามทวีปด้วยความปลอดภัยโมะ! อย่าลืมพกข้าวกระป๋องโนพอนไปกินระหว่างทางด้วยนะโมะ!"

"ขอบใจมากนะคุณเจ้าหน้าที่ศุลกากรโนพอน" รีนพยักหน้าตอบรับอย่างสุขุม มือขวากำก้ามเบรกหน้าพร้อมตบเกียร์หนึ่งเสียงดัง กึ๊ก! "จิตวิญญาณแห่งสองจังหวะจะนำพาความเจริญรุ่งเรืองและกลิ่นอายแห่งยูมีร์ไปประกาศศักดาที่สถาบันทอร์สเอง"

บรืนนนน— แป๊ดดดดดดดดดดดดดดดดดดดด!

เพียงแค่รีนปล่อยคลัตช์และกระแทกคันเร่งลงไปครึ่งปลอก ยางหลังขนาดร้อยสามสิบสแลชเจ็ดสิบก็ตะกุยพื้นหินอ่อนทองคำจนเกิดควันยางไหม้ผสมควันสองจังหวะพุ่งตลบอบอวล ตัวรถ Serpico SS ทะยานพุ่งแหวกอากาศออกจากประตูด่านตรวจหลวง ดิ่งตรงเข้าสู่ ถนนซูเปอร์ไฮเวย์ลอยฟ้าเชื่อมข้ามไททัน (Trans-Titan Superhighway Route 1) ในทันที!

ถนนไฮเวย์ลอยฟ้าเส้นนี้คือสิ่งปลูกสร้างทางวิศวกรรมอันน่าอัศจรรย์ใจ มันคือสะพานคอนกรีตเสริมเหล็กกล้าออร์บัลกว้างแปดเลนที่ทอดยาวลอยอยู่เหนือชั้นบรรยากาศและทะเลหมอก เชื่อมต่อระหว่างหลังไททันวาฬหิมะ Ymir เข้าสู่แผ่นดินใหญ่ของจักรวรรดิเอเรโบเนีย ทิวทัศน์เบื้องล่างมองเห็นเทือกเขาสลับซับซ้อนและทุ่งหญ้าเขียวขจีที่ทอดยาวไกลสุดลูกหูลูกตา ลมปะทะความเร็วหนึ่งร้อยกิโลเมตรต่อชั่วโมงซัดชายเสื้อคลุมบิชต์ทองคำของรีนจนสะบัดส่งเสียงพรึ่บพั่บดั่งปีกของพญานกอินทรีทอง!

🚂 ช่วงที่ 2: ศึกรมควันขบวนรถไฟด่วนจักรวรรดิ และการโบกมือทักทายทรงเกียรติ

หลังจากควบรถบนเส้นทางไฮเวย์ลอยฟ้ามาได้ราวสิบห้านาที ทางหลวงแปดเลนก็ค่อยๆ ลาดต่ำลงมาตีโค้งเลียบขนานชิดติดกับ "ทางรถไฟด่วนสายเหนือแห่งจักรวรรดิ" (Imperial Northern Railway) ซึ่งเป็นเส้นทางคมนาคมระบบรางหลักที่เชื่อมระหว่างหัวเมืองภาคเหนือสู่นครหลวง Heimdallr และนครทริสต้า (Trista)

และในจังหวะนั้นเอง ขบวนรถไฟด่วนพิเศษหัวรถจักรดีเซลไฟฟ้าขนาดยักษ์สิบสองตู้โดยสาร กำลังแล่นคู่ขนานมาด้วยความเร็วคงที่ประมาณหนึ่งร้อยสิบกิโลเมตรต่อชั่วโมง เสียงหวูดรถไฟดังกังวาน หวูดดดดดด— ปู๊น! ปู๊น! พร้อมกับเสียงลูกสูบดีเซลไฟฟ้ากระหึ่มเป็นจังหวะหนักแน่น

"โอ้โห... นั่นมันขบวนรถไฟด่วนสายเหนือนี่นา"

รีนเหลบลืมตามองลอดแว่นตาดำชวาเซอร์ เห็นตัวรถไฟสีน้ำเงินคาดทองกำลังวิ่งอยู่ข้างๆ ในระยะห่างเพียงไม่ถึงสิบเมตร คันเร่งในมือขวาของเขาเริ่มกระตุกด้วยสัญชาตญาณของนักบิดสองจังหวะที่ปฏิเสธการวิ่งตามหลังสิ่งใดบนโลก

"ในเมื่อวิ่งขนานกันแบบนี้... ข้าขอใช้โอกาสนี้เผยแพร่วัฒนธรรมและกลิ่นอายแห่งจิตวิญญาณลูกสูบเดี่ยวให้ชาวจักรวรรดิได้ประจักษ์สักหน่อยเถอะ!"

รีนตบเกียร์ลงเกียร์สี่ กระแทกคันเร่งเปิดวาล์วพุ่งแซงขึ้นไปขนาบข้างตู้โดยสารชั้นสองและชั้นสามของขบวนรถไฟด่วนในทันที! ปลายกระบอกท่อสูตรแดงบางทรายที่ไร้ไส้กรองเก็บเสียง แผดเสียงแหลมสูงดั่งใบเลื่อยตัดแผ่นสังกะสี แป๊ดๆๆๆๆๆๆ! สนั่นหวั่นไหวไปทั่วรางรถไฟ พร้อมกับพ่นกลุ่มควันขาวข้นคลั่กดั่งระเบิดควันสงคราม ม้วนตลบเป็นเกลียวคลื่นทะลักเข้าสู่ช่องลมระบายอากาศและบานหน้าต่างกระจกที่เปิดแง้มรับลมของตู้รถไฟโดยตรง!
