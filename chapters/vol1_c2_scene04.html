🤼 ช่วงที่ 1: สุนทรพจน์แบ่งชนชั้น & ชะตากรรมของเสื้อขาวและเสื้อเขียว

เปลวเพลิงที่ลุกโชนบนจอภาพ Orbal TitanTron 16K ค่อยๆ ม้วนตัวเปลี่ยนเป็นกราฟิกตราสัญลักษณ์ประจำห้องเรียนแต่ละห้องของสถาบันการทหารทอร์ส แสงไฟสปอตไลต์นับสิบดวงบนเพดานโดมทองคำรวมศูนย์สาดส่องลงมายังกึ่งกลางเวทีสังเวียน จุดที่ อาจารย์ใหญ่วินซ์ แมคแวนไดค์ (Principal Vince McVandyck) กำลังยืนเท้าสะเอวอย่างสง่าผ่าเผย สูททักซิโด้สีกรมท่าเข้มสั่งตัดขลิบทองคำแท้สะท้อนแสงวิบวับ ลำโพงออร์บัล 500,000 วัตต์คำรามเสียงเบสต่ำเป็นจังหวะกดดันหัวใจ

วินซ์ยกไมโครโฟนทองคำ 24K ขึ้นจ่อริมฝีปาก แผดเสียงต่ำแหบพร่าแต่น่าเกรงขามดังกัมปนาททะลุเพดานหอประชุม:

"เอาล่ะ... ไอ้พวกเด็กใหม่ทั้งหลาย! หลังจากที่พวกแกได้ยลโฉมคณาจารย์ผู้ที่จะมาคอยเฆี่ยนตีและรีดเร้นศักยภาพบนสังเวียนของพวกแกแล้ว... มันก็ถึงเวลาสำหรับการจัดสรร 'ชนชั้นและห้องเรียน' ที่แท้จริงของพวกแกในสถาบันทอร์สแห่งนี้!"

วินซ์กวาดสายตาดุร้ายไปทางปีกขวาของหอประชุม... จุดที่กลุ่มนักเรียนในชุดสูทเครื่องแบบสีขาวบริสุทธิ์ขลิบทองคำและเงินของบรรดาลูกหลานขุนนางชั้นสูงนั่งเรียงรายกันอยู่อย่างโอ่อ่า

วินซ์ชี้ไมค์ตรงดิ่งไปยังกลุ่มชุดขาวอย่างไม่เกรงใจใคร:

"เริ่มจากพวกแก... ไอ้พวกนักเรียนขุนนางชุดขาว! พวกแกจงไสหัวไปกองรวมกันที่ Class I และ Class II ซะ!"

เสียงของวินซ์กระแทกใส่ไมค์จนลำโพงสั่นสะท้าน: "จงไปเสพสุขกับความมั่งคั่งร่ำรวยที่พ่อแม่ของพวกแกกอบโกยและหามาประเคนให้พวกแกตั้งแต่ลืมตาดูโลก! หอพักนักเรียนขุนนางระดับซูเปอร์ลักชัวรี ปูพรมเปอร์เซียทอมือ โคมระย้าแชนเดอเลียร์คริสตัลโบราณ ห้องอาบน้ำหินอ่อนพร้อมน้ำแร่ออนเซ็นส่วนตัว และคนรับใช้คอยประคองป้อนอาหาร... กำลังรอต้อนรับพวกแกอยู่แล้ว! ไปนอนแช่ความสบายให้สมกับสายเลือดผู้ดีของพวกแกซะ!"

เฮฮฮฮฮฮฮฮฮฮฮฮฮฮฮฮฮฮ!

นักเรียนขุนนางชุดขาวทั้งชายและหญิงใน Class I และ II ต่างพากันลุกขึ้นยืนประสานมือ ปรบมือเสียงดังกึกก้องอย่างทรงเกียรติ ใบหน้าของแต่ละคนเต็มไปด้วยความภาคภูมิใจและรอยยิ้มพึงพอใจ ไม่มีใครมองว่าคำว่า "ไสหัวไปเสพสุข" ของวินซ์คือคำด่าทอ หากแต่มองว่ามันคือการยอมรับในอภิสิทธิ์ชนชั้นสูงตามตรรกะอันชอบธรรมของจักรวรรดิเอเรโบเนีย!

จากนั้น วินซ์หันขวับมาทางปีกซ้ายของหอประชุม... จุดที่นักเรียนในชุดสูทเครื่องแบบสีเขียวขี้ม้าของบรรดาสามัญชน คนธรรมดา และพ่อค้าเผ่าโนพอนนั่งเบียดเสียดกันอยู่

วินซ์เลิกคิ้ว แสยะยิ้มเย้ยหยัน แล้วแผดเสียงใส่ไมค์ลั่นฮอลล์:

"และสำหรับพวกแก... ไอ้พวกนักเรียนสามัญชนชุดเขียว! ทั้งมนุษย์และโนพอน... ไอ้พวกรากหญ้าก้นซอยทั้งหลาย!"

"พวกแกจงไปกองรวมกันที่ Class III, Class IV และ Class V ซะ!"

วินซ์ชี้นิ้วกราดอย่างดุเดือด: "พวกแกจะได้เข้าพักใน 'หอพักนักเรียนสามัญชน' สุดแสนจะธรรมดา ไร้ซึ่งความหรูหรา ไร้ซึ่งพรมเปอร์เซีย เตียงนอนไม้สองชั้นธรรมดาๆ ห้องน้ำรวม และอาหารเช้าตามอัตภาพ ที่พวกแกจะต้องใช้ชีวิตเยี่ยงคนธรรมดาสามัญไปจนวันตาย! อย่าได้สะเออะมาร้องขอความเท่าเทียมหรือความหรูหราใดๆ จากข้า... ถ้าจะโทษใคร ก็จงก้มหน้า 'โทษพ่อแม่ของพวกแกซะ' ที่ทำให้พวกแกเกิดมาเป็นแค่คนธรรมดา ไม่มีปัญญาจ่ายค่าหอพักห้าดาวให้พวกแก!"

ฮูเร่รรรรรรร! เฮฮฮฮฮฮฮฮฮฮฮฮฮฮฮฮฮฮ!

ทันใดนั้น... สิ่งที่ควรจะเป็นความขัดแย้งทางชนชั้น กลับกลายเป็นเสียงโห่ร้องยินดีกึกก้องจนหอประชุมแทบแตก!

บรรดานักเรียนสามัญชนเสื้อเขียวต่างกระโดดชูกำปั้นขึ้นฟ้าอย่างฮึกเหิม กอดคอกันหัวเราะร่าด้วยความภาคภูมิใจที่ตนเองได้อยู่ห้องเรียนสามัญชน ขณะที่เหล่านักเรียนและพ่อค้าเผ่าโนพอนแถวหลังต่างกระโดดตัวลอยจนหูยาวๆ โบกสะบัดพึ่บพั่บ ตะโกนประสานเสียงกวนประสาท:

"ท่านอาจารย์ใหญ่วินซ์พูดแทงใจดำที่สุดโมะ! โทษพ่อแม่โมะ! แต่หอพักธรรมดาก็มีเตียงไม้สองชั้นให้นอนฟรีโมะ! มีข้าวต้มผักแถมให้ทุกเช้า ประหยัดเงินมิราไปส่งให้ตระกูลที่โฮมสวีทโฮมได้เยอะแยะเลยโมะ!"

ทุกความผิดปกติ... กลายเป็น "ความโคตรปกติธรรมดา" ของโลกใบนี้อย่างไร้รอยต่อ!

🌲 ช่วงที่ 2: คำสั่งเนรเทศ Class VII สู่ป่า & สองอาจารย์สาวซิงร่วมชะตากรรม

วินซ์ แมคแวนไดค์ ยืนกอดอก หัวเราะในลำคออย่างพึงพอใจต่อเสียงตอบรับอันดังกึกก้องของทั้งสองฝั่ง จากนั้นเขาลดแขนลง ก้าวเดินช้าๆ มาหยุดอยู่ตรงริมขอบเวทีฝั่งด้านหน้า

สายตาดุร้ายประหนึ่งพญาอินทรีล่าเหยื่อ กวาดต่ำลงมายังพื้นที่ว่างกว้างขวางเบื้องล่าง... จุดที่ ชุดโซฟาหลุยส์ VIP ทองคำ 24K ตั้งตระหง่านอยู่โดดเด่นเป็นเอกเทศเพียงกลุ่มเดียว

บนเบาะกำมะหยี่สีแดงเลือดหมูราคาแปดหลักนั้น สมาชิกนักเรียนใหม่ทั้งเก้าคนใน ชุดสูทเครื่องแบบสีแดงชาด (Crimson Blazers) กำลังนั่งเรียงรายกันอยู่ ท่ามกลางความเงียบสงบที่เริ่มแผ่ปกคลุม

วินซ์ยกไมโครโฟนทองคำขึ้นจ่อปากอีกครั้ง เสียงกระซิบผ่านไมค์ดังก้องกังวานจนขนหัวลุก:

"และบัดนี้... มาถึงพวกแก... ไอ้พวกชุดแดงบนโซฟาหรูหราเกินหน้าเกินตาคนอื่น!"

วินซ์ชี้ไมค์ตรงดิ่งลงมายังร่างของรีนและเพื่อนร่วมชั้น:

"พวกแกคือ Main Event ตัวจริงเสียงจริงของสถาบันทอร์สในปีการศึกษา S.1204 นี้! พวกแกมันคือตัวประหลาดอันทรงเกียรติ ที่ข้าจงใจเอาไอ้พวกขุนนางสายเลือดเย่อหยิ่ง กับไอ้พวกสามัญชนรากหญ้า มาจับปั่นรวมกันในเครื่องปั่นมวยปล้ำ เพื่อสถาปนาเป็นห้องเรียนพิเศษที่ไม่มีใครเหมือนในนาม... Class VII!"

วินซ์เว้นจังหวะ แสยะยิ้มกว้างจนรอยเหี่ยวย่นบนใบหน้าขยับเป็นริ้ว:

"แต่ความพิเศษของพวกแกมันไม่ได้หยุดอยู่แค่ชื่อห้องเรียนหรอกโว้ย... เพราะพวกแกมันพิเศษมาก... พิเศษจนกระทั่ง 'พวกแกไม่มีหอพัก' ให้ซุกหัวนอนแม้แต่ห้องเดียว!"

กึก...

คำประกาศนั้นทำเอาบรรยากาศในหอประชุมพลันเงียบกริบลงในพริบตา วินซ์สูดลมหายใจลึกแล้วแผดเสียงหัวเราะลั่น:

"ฮ่าๆๆๆๆ! ถูกต้องแล้ว! สถาบันทอร์สไม่มีห้องพักในหอขุนนางให้พวกแก และไม่มีเตียงนอนในหอสามัญชนให้พวกแกแม้แต่เตียงเดียว! สิ่งที่พวกแกทั้งเก้าคนต้องทำหลังจากก้าวเท้าพ้นประตูหอประชุมนี้ คือการเก็บข้าวของ แบกสัมภาระ แบกเต็นท์ และถือมีดพร้า... เดินเท้าเข้าไป 'หักร้างถางพงสร้างที่นอนกันเองในป่าหลังโรงเรียน' โน่น!"

"พวกแกต้องไปนอนกลางดิน กินกลางทราย ฟันฝ่าดงหญ้า ดงหนาม ยุงป่า และลมหนาวด้วยสองมือของพวกแกเอง! ใครที่ทนไม่ได้... ก็จงเก็บกระเป๋ากลับบ้านไปซะ!"

ทว่า... คำสั่งสุดวิปริตของวินซ์ยังไม่จบลงเพียงแค่นั้น!

วินซ์ผายมือขวากว้างไปยังปีกเวทีด้านหลัง... จุดที่สองอาจารย์สาวทรงสะบึมยืนสงบนิ่งอยู่ข้างโพเดียม

"และเพื่อความยุติธรรมอันสูงสุดของสถาบันทอร์ส... ข้าจะไม่ปล่อยให้พวกแกต้องไปตกระกำลำบากในป่าเพียงลำพัง!"

วินซ์ตะโกนกรอกไมค์เสียงลั่น: "สองอาจารย์สาวคนสวยแห่งสถาบันทอร์สตรงนี้... อาจารย์ซาร่า วาเลสไตน์ หัวหน้าภาควิชาอิสระศึกษา และ อาจารย์แมรี่ อัลเธอิม หัวหน้าภาควิชาดุริยางคศิลป์... คือ 'อาจารย์ประจำชั้นร่วม' ของพวกแกห้อง Class VII!"

"และตามกฎเหล็กของสมาคม TWF... อาจารย์ประจำชั้นต้องร่วมทุกข์ร่วมสุขกับนักเรียน! ดังนั้น... ทั้งซาร่าและแมรี่ จะต้องเก็บกระเป๋าเสื้อผ้า หอบหมอน มุ้ง และเต็นท์... เดินเท้าเข้าไปหักร้างถางพง นอนกลางดินกินทรายร่วมชะตากรรมเดียวกับพวกแกในป่าหลังโรงเรียนด้วยโว้ยยยยยย!"
