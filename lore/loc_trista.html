#Trista #Thors #Class VII #TWF Arena

(มหานครเต่าจักรกลโบราณ ศูนย์กลางการศึกษา คาสิโนสูบเงินนักเรียน สังเวียนมวยปล้ำประจำทวีป และดินแดนแห่งเทศกาล Purge)

1. ภาพรวมและลักษณะทางกายภาพ (Overview & Physiology)

  • ประเภทสถานที่: ไททันสิ่งมีชีวิตชีววิทยาผสมเต่าจักรกลโบราณ (Ancient Mechanical-Turtle Class Titan)
  • สมญานาม: "Trista TWF — เมืองแห่งเสียงหวูดรถไฟ คาสิโนหมดตูด สังเวียนข้าวกระป๋อง และสัปดาห์ The Purge"
  • ผู้ปกครองพื้นที่: วินซ์ แมคแวนไดค์ (Vince McVandyck / Mr. McMahon) ครูใหญ่สถาบัน Thors และประธานกรรมการบริหารสูงสุดแห่งสมาคมมวยปล้ำ TWF ร่วมกับสภาเมืองทริสต้า
  • ทำเลที่ตั้ง: ลอยตัวอยู่ในทะเลเมฆระยะไม่ไกลจาก Titan Heimdallr (นครหลวง) เดินทางเชื่อมต่อกันได้ด้วยรถไฟข้ามทะเลเมฆประจำวัน

2. สถานที่สำคัญภายใน Titan Trista (Key Landmarks)

🚉 2.1 สถานีรถไฟหัวลำโพงแห่งทริสต้า (Hua Lamphong Central Station of Trista)

  • บรรยากาศหลัก: โครงสร้างอาคารหลังคาเหล็กโค้งทรงโดมคลาสสิก ถ่ายทอดความย้อนยุค สมจริง และอบอ้าวสไตล์สถานีรถไฟหัวลำโพงดั้งเดิม
  • สัญลักษณ์เฉพาะตัว:
  • นกพิราบออร์บัล (Orbal Pigeons): บินเกาะตามโครงเหล็กและคานหลังคา คอยถ่ายมูลออร์บัลใส่หัวขุนนางที่เดินผ่าน
  • เสียงประกาศลำโพงพร่าๆ: ประกาศเวลาเดินรถไฟข้ามทะเลเมฆไป Heimdallr ด้วยภาษาไทยผสม Bash Script สลับกับเสียงหวูดดีเซลดังสนั่น:
    "เรียนผู้โดยสารโปรดทราบ... ขบวนรถไฟ Orbal Express ที่ $ sudo service train start จะเทียบชานชาลาที่ 3..."
  • พ่อค้าโนพอนชานชาลา: เดินห้อยเข่งหาบขายข้าวกระป๋อง Nopon, ข้าวแกงเขียวหวานเนื้อฉลามเมฆ, และตู้กดกาแฟ Remnant ให้แก่ผู้โดยสารก่อนขึ้นรถไฟ

🎰 2.2 คาสิโนประจำสถาบัน Thors (Thors Student Imperial Casino)

  • เจ้าของและผู้บริหาร: บริหารงานโดยตรงโดย วินซ์ แมคแวนไดค์ (Vince McVandyck) ร่วมกับบอร์ดบริหาร Thors 100%
  • โมเดลธุรกิจทุนนิยมสุดหน้าด้าน (Absurd Student Monetization Model):
  • สถาบันมองว่า "ลำพังแค่เก็บค่าเทอมกับค่าบำรุงการศึกษาคงไม่พอต่อการพัฒนายุทโธปกรณ์และจ่ายเงินปันผลผู้ถือหุ้น" จึงตั้งคาสิโนขนาดใหญ่ไว้กลางเมืองเพื่อสูบเงินค่าขนมและเงินกระเป๋าของนักเรียนกลับเข้าคลังสถาบัน
  • นักเรียน Class I-II (ขุนนาง): โดนสูบเงินมิรานับล้านจากการเล่นสล็อตและรูเล็ตออร์บัล
  • นักเรียน Class III-V (สามัญชน): โดนสูบจนหมดตูดตั้งแต่วันแรกของเดือน ต้องประทังชีวิตด้วยข้าวกระป๋องโนพอนแจกฟรี
  • อาจารย์ Sara Valestein: ลูกค้า VIP ประจำคาสิโน ที่มักเอาเงินเดือนออกคืนแรกไปถลุงเล่นโป๊กเกอร์จนหมดตูด แล้วต้องไปยื่นญัตติต่อ "สภาฮาเร็ม" (Class VII + เอลิเซ่ + อัลฟิน) เพื่อขออนุมัติงบจากชีคหนุ่มรีน ชวาเซอร์ มาจ่ายเคลียร์หนี้ให้ประธานวินซ์ แลกกับมติลงโทษให้อ้าขาโดนรีนแทงสด 2 รู!

🏢 2.3 เขตหอพักนักเรียนแบ่งชนชั้น (Class I - V Student Dormitory Sector)

  • หอพักขุนนาง (Class I - II Dormitories):
  • คฤหาสน์หรูหราทรงยุโรป มีคนรับใช้ส่วนตัว สระว่ายน้ำอุ่น และอ่างอาบน้ำทองคำแท้สำหรับนักเรียนตระกูลขุนนางชั้นสูง
  • หอพักสามัญชน (Class III - V Dormitories):
  • หอพักอัดแน่นสไตล์ห้องเช่ารากหญ้า ผนังห้องบางจนได้ยินเสียงเพื่อนข้างห้องสวดมนต์ Bash Script มีสภาพเหมือนค่ายซ้อมมวยปล้ำดั้งเดิม
  • หมายเหตุสำคัญ:
  • ก๊วน Class VIIไม่ได้พักที่หอพักเหล่านี้! (ข้อมูลโครงสร้างและหอพักพิเศษของ Class VII จะนำไปเล่นอย่างละเอียดในไฟล์ Location Bible: Thors Military Academy)

🤼‍♂️ 2.4 สังเวียนมวยปล้ำประจำเมือง (TWF Trista Arena)

  • บทบาท: สังเวียนมวยปล้ำอาชีพขนาดยักษ์ใจกลางเมืองทริสต้า บริหารโดยประธาน วินซ์ แมคแวนไดค์
  • บรรยากาศและความบันเทิง:
  • เป็นสถานที่จัดศึกมวยปล้ำประจำสัปดาห์ของจักรวรรดิ ถ่ายทอดสดระบบ Pay-Per-View ข้ามจักรวาล คลาคล่ำไปด้วยแฟนคลับชาวเมือง ประชาชนข้ามไททัน และชาวต่างดาว (เช่น เผ่า Krogan และ Turian) ที่เดินทางผ่าน Mass Relay มาซื้อตั๋วดูแมตช์การแข่งขัน
  • มีเก้าอี้พับ โต๊ะไม้ และบันไดเหล็กวางสำรองไว้ใต้สังเวียนอย่างเปิดเผย สำหรับให้ก๊วน Class VII ชาย (Elliot, Jusis, Machias, Gaius) หยิบขึ้นมาใช้ฟัดกันบนเวทีตามคำสั่งของประธานวินซ์

🎓 2.5 สถาบันการทหาร Thors และ 6 ศาสตราจารย์สุดเพี้ยน (Thors / TWF Faculty)

  • ระบบการศึกษา: ดูรายละเอียดหลักสูตรมวยปล้ำ PPV, การสอบ Steel Cage & Royal Rumble, และ 6 คณาจารย์สุดเพี้ยน (อ.ซาร่า, อ.แมรี่, อ.โคดี้ โรดส์, อ.บูเกอร์ ที, อ.บิ๊ก โชว์, อ.อาร์-ทรูธ) ใน 📄 Thors_TWF_Curriculum_and_Faculty_Lore.md

🚨 3. เทศกาลประเพณีประจำปี: The Purgeแห่งทริสต้า (The Annual Trista Purge - 168 Hours)

  • ลักษณะเฉพาะและเงื่อนไขความรู้:
  • เป็น "เทศกาลลับเปิดเผย" ที่ชาวเมืองทริสต้าทุกคนและนักเรียน Thors ชั้นปีที่ 2 รู้จักกันเป็นอย่างดี
  • ความลับของปี 1: นักเรียนชั้นปีที่ 1 (รวมถึงเด็กใหม่ Class VII) จะ "ไม่มีทางรู้ล่วงหน้าเด็ดขาด" ว่าเทศกาลนี้มีอยู่จริง จนกว่าเสียงหวูดรถไฟสถานีหัวลำโพงทริสต้าจะเปิดหวูดไซเรนเตือนภัยยาว 3 นาทีเต็ม เพื่อส่งสัญญาณเริ่มต้นเทศกาล!
  • สภาวะสมรภูมิเมือง (Urban War Zone Condition):
  • 168 ชั่วโมงเต็ม (7 วัน 7 คืน): กฎหมายเมืองและระเบียบสถาบันทั้งหมดจะถูกระงับชั่วคราวตลอดระยะเวลา 1 สัปดาห์ สภาพเมืองทริสต้าทั้งเมืองจะถูกยกระดับกลายเป็น "แดนสงครามกลางเมือง (Full-Scale Urban War Zone)" โดยสมบูรณ์
  • มีการสร้างสิ่งกีดขวาง กระสอบทราย บังเกอร์ไม้ และตั้งป้อมยิงก้อนหิน/เก้าอี้พับตามสี่แยกถนน ชาวเมืองและนักเรียนจับกลุ่มถืออาวุธอนาล็อกและท่อเหล็กลุยตะลุมบอนกันทั่วทุกตารางนิ้ว
  • 📜 กฎเหล็ก 3 ข้อแห่ง The Purge (3 Sacred Rules):
  • ห้ามเล่นถึงตาย (No Fatalities): ห้ามสังหารหรือทำให้เกิดการเสียชีวิตโดยเจตนา (แม้จะเป็นสงครามก็ต้องยิงสลบหรือทุบสลบเท่านั้น)
  • ห้ามข่มขืน (No Sexual Assault / Rape): ห้ามกระทำชำเราหรือข่มขืนใจทางเพศโดยเด็ดขาด (ความใคร่ทั้งหมดต้องผ่านความยินยอมหรือการยื่นเรื่องสวัสดิการ H-Factor จาก Eros-Vault เท่านั้น)
  • ห้ามทำให้พิการถาวร (No Permanent Maiming/Disability): ห้ามตัดอวัยวะ ทำลายดวงตา หรือทำให้พิการถาวร
  • ความวุ่นวายระหว่างเทศกาล (Purge Chaos Dynamics):
  • นอกเหนือจากกฎเหล็ก 3 ข้อดังกล่าว "ทุกการทำสงครามและการกระทำในเมืองถือว่าถูกกฎหมาย 100%!"
  • การแก้แค้นและปล้นสะดม: นักเรียนสามัญชนจับกลุ่มถือเก้าอี้พับและท่อเหล็กบุกปล้ำเอาคืนพวกขุนนาง Class I-II, พ่อค้าโนพอนตั้งโต๊ะเปิดบ่อนรับแทงผลการตะลุมบอนกลางถนน, และอาจารย์ Sara ฉวยโอกาสวิ่งราวเงินชิปในคาสิโน
  • การเอาตัวรอดของ Class VII: เป็นช่วงเวลาที่ก๊วน Class VII ชายต้องแสดงความเก๋า งัดท่ามวยปล้ำ BGM พ่นน้ำ และไม้ตาย WWE มาใช้ป้องกันหอพักและเอาชีวิตรอดตลอด 168 ชั่วโมงในแดนสงคราม

4. Active Flags & Scene Integration (คำแนะนำการใช้ในฉาก)

  • ฉากเดินทาง / บรรยากาศ (ST-05): ตัวละครนั่งรถไฟข้ามทะเลเมฆมาจาก Heimdallr ก้าวลงชานชาลาสถานีหัวลำโพงทริสต้า ได้กลิ่นข้าวแกงเขียวหวานโนพอน และยินเสียงประกาศลำโพงพร่าๆ
  • ฉากทุนนิยม / ตลก (ST-04 / ST-06): อาจารย์ Sara ยืนร้องไห้หน้าคาสิโน Thors เพราะโดนตู้สล็อตสูบเงินเดือนหมดตูด หรือขุนนางหน้ามืดเพราะเสียเงินมิราในคาสิโนของโรงเรียนตัวเอง
  • ฉากตะลุมบอน / มวยปล้ำตลก (ST-02 / ST-06): เสียงไซเรนเตือนภัย The Purge ดังขึ้นกลางเมือง เมืองเปลี่ยนเป็นแดนสงคราม เด็กปี 1 ยืนเหวอ ขณะที่ก๊วน Class VII ชายหยิบเก้าอี้พับเตรียมลุยตลอด 168 ชั่วโมง
